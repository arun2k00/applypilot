# Code of conduct

Treat contributors and users with respect. Give specific, constructive feedback. Respect differences in background and experience. Protect personal information shared in support requests, code reviews, and discussions.

Harassment, threats, discriminatory language, personal attacks, and sharing another person's private information without permission are unacceptable. Maintainers may remove content or restrict participation. Report incidents to the repository maintainers using the project's private contact channel when the public repository is launched.
